# Contract — Internationalisation (003)

**Feature**: 003-i18n-ui-redesign · **Date**: 2026-10-31

Contrat additif aux features 001/002. Définit la résolution de langue, le
catalogue des textes et la table des traductions bibliques. Le comportement
UI (boutons icônes, deux colonnes, charte) est dans
[ui-behavior.md](ui-behavior.md).

## Résolution de langue

| Règle | Description |
| --- | --- |
| Source | `chrome.i18n.getUIanguage()` — langue de l'interface du navigateur, aucune permission |
| Résolution | `resolveUiLocale(language: string): UiLocale` — préfixe `fr` (insensible à la casse, variantes régionales incluses) → `"fr"` ; tout le reste (y compris valeur absente) → `"en"` (fallback FR-002) |
| Moment | au chargement du popup (une fois par ouverture) ; un changement de langue navigateur s'applique à la prochaine ouverture |
| Réglage | aucun — la langue n'est pas persistante ni configurable (FR-004) |
| Service worker | même résolution (pour les textes partagés, ex. messages d'erreur du tirage) ; les journaux développeur restent hors catalogue |

locale ; les messages de validation et les textes de boutons des
features 001/002 migrent tels quels vers le catalogue (comportement
inchangé).

## Traductions bibliques

Table `Record<UiLocale, { id, name }>` dans `src/shared/bible/draw.ts`
(`translationForLocale(locale)`) — même endpoints que 001, aucune nouvelle
intégration :

| Locale | id | name |
| --- | --- | --- |
| `fr` | `fra_lsg` | Louis Segond 1910 |
| `en` | `eng_kjv` | King James Version |

Le verset tiré porte `translationId`/`translationName`/noms de livres de
la traduction choisie. Le décompte (`repetition >=
repetitionsBeforeLongBreak` → longue pause) et le cycle sont inchangés.

## Stockage

Aucune nouvelle clé persistée. Changements :

| Clé | Changement |
| --- | --- |
| `settings` | champ `translationId` **supprimé** (mort) — valeurs stockées ignorées par la fusion de `readSettings` |
| `bookIndex` | devient **préfixée par traduction** : `bookIndex:fra_lsg`, `bookIndex:eng_kjv` (l'index diffère entre traductions) ; TTL 30 jours inchangé |
| `StorageKey` | union étendue : `"settings" \| "currentCycle" \| "pomodoroState" \| \`bookIndex:${string}\`` |

`pomodoroState`, `currentCycle`, `settings` (autres champs) : inchangés
([../002-pomodoro-timer/contracts/storage-schema.md](../002-pomodoro-timer/contracts/storage-schema.md)).
