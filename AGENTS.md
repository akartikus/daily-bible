# Instructions pour l'agent

- Respecter l'architecture et les conventions existantes.
- Lire uniquement le contexte utile à la demande : commencer par docs/context/index.md, puis les fichiers ciblés.
- Si la documentation de la  feature ou tache demandée n'est pas encore repertorié dans docs/context, ajoute le fichier .md et met à jour docs/context/index.md.
- Avant toute action Spec Kit, afficher la feature active et vérifier qu'elle correspond à ma demande.
- Pour une tâche ciblée, vérifier les dépendances et ne modifier que son périmètre sans mon accord.
- Cocher une tâche dans tasks.md uniquement après implémentation et vérification.
- Lancer les tests pertinents et déclarer explicitement les échecs ou les tests non exécutés.
- Après changement architectural, proposer la mise à jour de la documentation concernée.
